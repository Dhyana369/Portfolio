# ✦ Dhyana's Portfolio

A creative and immersive personal portfolio inspired by Van Gogh’s *Starry Night*, designed to blend art, motion, and technology into a single interactive experience.

## ✨ Features

* Custom shooting-star cursor effect
* Animated starfield background
* Glassmorphism-inspired navigation
* Interactive 3D flip project cards
* Responsive layout for desktop & mobile
* Artistic UI inspired by *Starry Night*
* Smooth scrolling and animated transitions
* Contact form integration using Formspree

## 🎨 Design Inspiration

This portfolio is heavily inspired by the atmosphere and movement of Van Gogh’s *The Starry Night*, combining cosmic visuals with modern web interactions to create a dreamy digital experience.
